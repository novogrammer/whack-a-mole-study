# BGM・SEの制作メモ

制作時の狙いと、音楽・ゲームの進行を組み立てた経緯を残す。BGM・SEはLogic Proで制作した。再生タイミングなどの実装仕様は[ゲーム仕様](game-spec.md)を参照。

## テンポと曲の構成

最初に120 BPMを決めた。親しみやすさに加え、モグラの出現タイミングを120 BPMで作っていたため、それに合わせた。行進を思わせるテンポで、前向きな気分を促す狙いもある。

4拍子で各コードを1小節ずつ使い、全20小節・40秒とした。

| 区間 | コード | 小節数・時間 |
| --- | --- | --- |
| イントロ | F → G | 2小節・4秒 |
| 本編 | C → G → Am → F → F → Em/G → F → G を2回 | 16小節・32秒 |
| アウトロ | G → C | 2小節・4秒 |

本編は当初、C → G → Am → Fを4回繰り返していた。少しループが短く感じたため、16小節の長さを保ちながら、8小節の進行を2回繰り返す形に変更した。Em/Gは、Emのミをオクターブ上げ、ソを最低音にした第1転回形。

イントロのF → Gは「これから始まる感じ」、アウトロのG → Cは「Cに戻って終わった感じ」を出すために選んだ。

## 楽器と展開

最初はドラムだけで制作し、さまざまな展開を付けていた。その後コードを入れたくなり、コードを当てた段階で、前半のループを16ビート、後半をライドの裏打ちを使ったシンプルなパターンにした。後半はゲームの手数が増えるので、音楽も少し賑やかにしたかった。

コードには電子ピアノを使う。イントロとアウトロではメロディ、本編ではコードのバッキングを担当する。モグラの出現音が低めなので、BGMには高めで爽やかな響きが欲しくて選んだ。

さらにベースの音も欲しくなり追加した。各小節の頭にルート音を付点四分音符で置き、四分休符の後、コードの構成音を八分音符3つで鳴らす。

| 基本パターン | 付点四分音符 | 四分休符 | 八分音符3つ |
| --- | --- | --- | --- |
| 1 | 1度 | 休み | 5度 → 3度 → 5度 |
| 2 | 1度 | 休み | 1度 → 3度 → 5度 |

ベースを入れるタイミングは、聴きながら自然に感じる位置で決めた。

## SE

短いフレーズのSEもLogic Proで作曲した。音選びではCメジャースケールを意識した。

| 用途 | 音色・フレーズ | 狙い |
| --- | --- | --- |
| モグラの出現 | アタックが強めの電子楽器のベースで、ド・レ・ミの三連符 | 音が上がることで、モグラが出てくる感じを表す |
| 命中 | 木製打楽器で、八分音符のド・ソ | Cメジャースケールを意識した音選び |

## 音楽とシーンの切り替え

BGMの構成を軸に、シーンの長さや切り替えのタイミングを調整した。

アウトロでは、終了と結果を一度に表示する案も考えたが、2段階に分けた。「終わった。結果は？」という気持ちを大切にし、結果を待つ間を作るため。

| BGM開始から | 音楽・画面の流れ |
| --- | --- |
| 0〜4秒 | イントロ。「よーい」からカウントダウン |
| 4〜36秒 | 本編。モグラ叩きをプレイ |
| 36〜38秒 | アウトロ1小節目。「終了」を表示 |
| 38〜40秒 | アウトロ2小節目。BGMを残しながら結果を表示 |

最後の2小節はそれぞれ頭にクラッシュシンバルを鳴らし、終了表示・結果表示への切り替わりを伝える効果音の役割も持たせた。

## イントロとアウトロのメロディ

イントロはコードを同時に鳴らす代わりに、構成音を使ったメロディにした。当初の音列は、Fが「F3・A3・C4・F3」、Gが「G3・B3・G3・B3・D4・G4」。ありきたりに感じたため、最終的には休符を取り入れ、少し弾む感じに調整した。

冒頭はメロディがメインで流れるので、リズムの頭がわかるように、休符からは始めず音符で始めた。その後の休符で弾む感じを作っている。

アウトロは、意図的にべたっとした感じのままにしている。
